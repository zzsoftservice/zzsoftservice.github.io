清晰说明你的信息如何被处理

隐私政策

最后更新：2026 年 9 月 22 日 · 适用于 macOS 版 DeskWidgets

DeskWidgets 由 ZZSoft 提供。本政策说明应用处理哪些信息、什么情况下信息会离开你的 Mac，以及你可以如何管理这些信息。如有疑问，请联系 zzsoftservice@outlook.com。

简要说明：DeskWidgets 默认将日常配置与内容保存在你的 Mac，不要求注册 DeskWidgets 账户，也未集成广告或跨应用追踪 SDK。可选在线功能会连接外部服务；启用 iCloud 的版本还可能通过 Apple 同步支持的数据。因此，我们不会宣称“任何信息都绝不离开设备”。

一、本机保存的信息

应用可能保存倒计时名称与日期、显示方式与总天数、时钟城市与时区、计时器和专注设置、便签、任务及完成状态、启动器目标、文件引用、外观配置，以及组件内容缓存。应用和组件扩展通过本地 App Group 容器共享显示组件所需的数据。

文件功能保存你选择的项目的名称、路径和 macOS 安全作用域书签，用于再次访问已授权的项目；这不代表上传文件内容。当前照片相关信息包括所选文件的名称、尺寸等元数据。CPU、内存、磁盘、网络活动和电池等系统指标在本机处理。

二、可选的 macOS 权限

  • 日历：获得授权后读取相关日程的标题与时间，用于展示日程；应用不会创建或修改日历事件。
  • 提醒事项：获得授权后读取提醒事项，并可在你主动操作时更新完成状态。
  • 文件与文件夹：访问受你选择的项目及 macOS 授权范围限制；打开项目时会交给 macOS 或对应应用处理。

你可以拒绝授权，继续使用不依赖这些权限的功能。日历与提醒事项权限可在「系统设置 → 隐私与安全性」管理；不再使用的文件可从固定列表移除。DeskWidgets 不请求通讯录权限，天气也不使用自动设备定位。

三、可选的在线信息

配置或刷新在线来源时，你的 Mac 通过 HTTPS 直接连接对应服务。服务方会收到请求、IP 地址及正常连接所需的技术信息。DeskWidgets 发送应用名称形式的 User-Agent，而非唯一广告标识符。请求可能包含：

功能／服务方发送的信息用途
天气／Open-Meteo你输入的经纬度及天气查询选项获取所选位置的天气
RSS／你选择的订阅源订阅源 URL，包括其中的查询参数获取订阅内容
在线语录／Quotable随机语录请求获取语录
汇率／ExchangeRate-API所选基准货币获取换算汇率

服务方可能按其自身政策保留连接日志。截至本政策更新时，Open-Meteo 的政策说明日志可能包含 IP 地址及地理坐标，并在 90 天后删除。如果你不希望将某个精确私人位置发送给服务方，请不要输入该位置。不要在 RSS URL 中填写密码或私密令牌。不配置在线功能或移除来源，可以避免继续发起相关请求；已获取的内容可能仍保留在本地缓存中。

你打开的链接、应用和快捷指令受目标服务的隐私规则约束。我们无法控制外部服务，也不承诺其始终可用。

四、支持时才启用的 iCloud

默认本地构建未启用 iCloud 同步。如果你安装的版本支持并启用该能力，受支持的配置与内容可能保存在你 Apple 账户下的私有 CloudKit 数据库，并在设备间同步。该服务由 Apple 根据其隐私政策运营。DeskWidgets 不会收到你的 Apple 账户密码。文件引用同步并不等于向另一台 Mac 转移本地文件访问权限，可能需要重新授权。

五、支持邮件与本网站

当你主动发邮件联系我们时，我们会收到你的邮箱地址以及你发送的文字或附件。这些信息用于回复、排查问题及履行适用义务，不用于广告；邮件服务提供方也会处理邮件。发送前请遮盖私人内容，不要发送账户凭据。

本网站使用 GitHub Pages 托管。GitHub 可能为提供服务和保障安全处理 IP 地址及技术请求日志，具体见 GitHub 隐私声明。这些页面没有嵌入分析脚本、广告脚本或追踪 Cookie。

六、保存期限、删除与选择

本地内容会保留到你删除相应内容或应用数据。仅移除桌面组件不会删除其引用的已保存内容。卸载 macOS 应用后，容器、共享数据或备份可能仍存在；如需完全移除，请同时管理这些副本。如果不确定哪些文件属于 DeskWidgets，可联系支持，避免误删其他数据。

使用启用 iCloud 的版本时，可通过该版本支持的功能和 Apple 存储管理工具管理云端副本；本地删除、云同步和备份可能具有不同的保留行为。外部服务自行管理其日志。支持邮件仅在处理请求和履行适用义务合理所需的期间内保留。你可以联系我们申请访问、更正或删除曾发送给支持团队的信息，具体权利及例外以适用法律为准。

七、安全与共享

DeskWidgets 使用 macOS 沙盒权限、本地存储保护，以及 HTTPS 在线请求。我们不出售你的信息，也不将其用于广告。为处理支持请求，或依法需要时，我们可能向必要的服务提供方或有权机构提供相关支持信息。任何存储或传输方式都不能保证绝对安全，请妥善保护设备并做好备份。Apple、网站托管、邮件及在线服务提供方可能依据各自政策在其他国家或地区处理数据。

八、儿童与政策更新

DeskWidgets 是通用效率工具，不是专为收集儿童信息而设计的服务。如果你认为儿童向我们发送了个人信息，请联系我们处理。应用变化时，我们可能更新本政策；页首日期标识当前版本。重要变化将视情况通过应用或支持网站说明。
