适用范围与联系方式

更新日期：2026-10-11。本政策适用于 LIPEI ZHANG 提供的折间 FoldMuse 应用和本支持网站。隐私问题请联系 zzsoftservice@outlook.com。

应用不收集数据

FoldMuse 无需账户，不含广告、追踪或分析 SDK。应用不向开发者发送作品、图片、设备标识或使用记录，也不出售这些数据。

设备上的处理

工作区、操作记录、设置和保存的作品保存在应用本地目录。你通过系统照片选择器或文件选择器主动选择图片；应用只处理选中的文件，无需访问整个相册。导入图片在本地缩小并去除元数据，再嵌入作品文件。兼容设备的铰链角度只用于本地折叠交互，不会发送给开发者。

导出、分享与备份

导出或分享只由你主动发起。导出的 PNG 或 .origami 文件会交给你选择的应用、位置或服务。系统备份、iCloud 文件位置及外部分享服务遵循各自的政策和你的设置；这些副本不由开发者保管。

删除和管理数据

你可以在应用中移除纸面图片、删除作品。从作品列表移除的文件保留在「文件」App → FoldMuse → Recently Deleted，以便恢复；可在「文件」App 中永久删除。删除应用会移除其本地数据，已导出或备份的副本需要在对应位置单独管理。

支持邮件

如果主动向我们发送邮件，我们会收到你的邮箱地址、邮件内容和你选择提供的附件，用于回复和排查问题。邮件服务商也会处理邮件。请避免发送不必要的私人内容。支持往来仅在处理请求和履行适用义务所需期间保留；你可以通过支持邮箱请求访问、更正或删除相关信息。

本网站

本网站不嵌入广告、分析脚本或追踪 Cookie。网站由 GitHub Pages 托管，GitHub 可能为运行和保护服务而处理 IP 地址及技术请求日志，详见 GitHub 隐私声明。外部链接和邮件服务适用各自的隐私政策。

政策更新

功能或数据处理方式变化时，我们会更新此页面和更新日期。如认为有人通过支持渠道发送了不应提供的个人信息，请联系我们处理。
