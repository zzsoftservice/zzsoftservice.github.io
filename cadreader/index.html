Open supported 2D DXF drawings on iPhone and iPad. Organize files, inspect layers and layouts, search text, and measure—without creating an account.

Organize clearly

Import from Files, create nested folders, search, pin, rename, move, sort, and recover items from a 30-day Trash.

Inspect the drawing

Pan and zoom, switch layouts, manage layers, search drawing text, and review drawing-health information.

Measure carefully

Distance, angle, area, perimeter, continuous distance, object snapping, and explicit unit or scale confirmation.

Private by default

No account, advertising SDK, or cross-app tracking. Drawings stay in local app storage unless you choose to share them.

Built for mobile

A focused black-and-white interface, touch-friendly controls, and workflows designed for both iPhone and iPad.

Honest diagnostics

Unsupported content fails closed. Local diagnostics omit drawing contents and are shared only when you choose.

Current format boundary

This release previews supported entities in 2D ASCII DXF files through a limited built-in engine. DWG files can be imported and identified, but production DWG rendering is not included in this version. Always verify critical drawing information and measurements before consequential use.
