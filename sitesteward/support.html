SiteSteward

Support for your work on site.

Help, recovery steps and a direct support contact.

Get in touch

Email zzsoftservice@outlook.com. Include the app version, device model, iOS version and steps to reproduce the issue. Redact personal information in screenshots. Do not send passwords or an entire client project unless you deliberately choose to share it.

Try the sample project

Open Settings → Install demo project. The sample contains fictional data and can be removed. Settings → Help explains measurement, finance, export, recovery and permission alternatives.

Recover editing or a long operation

Use Settings → Recover editing drafts to continue unfinished input. Recovery tasks retain captured report, backup and restore inputs so an interrupted job can be retried. A preview is not a formally issued report until you issue it.

Keep an independent backup

Use project management or Settings to export a complete checked project package to Files or another chosen destination. A local backup is still on this device. Check the restored copy before removing originals; duplicate import normally skips identical data, while fork restore makes independent identities.

Permissions and unsupported hardware

Import existing images/files instead of taking a photo. Enter coordinates manually instead of granting location. Tasks remain visible without notifications. Hand drawing and reports work without LiDAR; AR has numeric and 2D alternatives.

Free access

All first-version features are free. There are no purchases or subscriptions to restore. This app does not require a sign-in account.
